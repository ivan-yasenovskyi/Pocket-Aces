# API Pocket Aces (+ бот тренувань)

Один процес робить дві речі:

1. **Telegram-бот** у групі команди: опитування про тренування, нагадування, `/hto`, `/stat`.
2. **API для сайту** (`http://localhost:4000/api`): вхід через Telegram, кабінет гравця, відповіді «Będę / Nie dam rady».

Сайт (`apps/web`) звертається на `/api/...`, а Next.js пересилає це сюди (див. `rewrites` у `apps/web/next.config.ts`).

## Запуск (Windows, PowerShell)

```
cd apps\api
npm install
copy .env.example .env
```

Відкрий `apps\api\.env` і встав токен від @BotFather після `BOT_TOKEN=`. Потім:

```
npm start
```

Має з'явитися `API працює: http://localhost:4000/api` і `Бот @… працює`.
Сайт запускай в **іншому** терміналі: `cd apps\web` → `npm run dev`.

## Вхід на сайт через Telegram

1. На сайті `/logowanie` → «Zaloguj się przez Telegram».
2. Відкривається бот → **Start**. Бот перевіряє, що ти в групі команди.
3. Сайт сам помічає підтвердження і відкриває кабінет `/hub`.
4. Перший раз гравець обирає свою картку. Помилився — адмін пише в групі `/vidvyazaty 11`.

Хто вийшов із групи, протягом 10 хвилин втрачає доступ до кабінету.

## Команди бота

| Команда | Хто | Що робить |
|---|---|---|
| `/hto` | усі | хто буде на найближчому тренуванні |
| `/rozklad` | усі | постійний розклад і найближчі тренування |
| `/stat` | усі | хто скільки разів відмічався за 30 днів |
| `/trening 24.10 19:00 Зал` | адмін | разове тренування з опитуванням |
| `/rozklad_dodaty вт 19:00 Зал` | адмін | постійне тренування щотижня |
| `/rozklad_vydalyty 1` | адмін | прибрати постійне тренування №1 |
| `/skasuvaty` | адмін | скасувати найближче тренування |
| `/vidvyazaty 11` | адмін | відв'язати картку гравця на сайті |
| `/matchi` | усі | список матчів (з номерами) |
| `/match 02.11 18:00 Суперник \| Зал` | адмін | додати матч — він одразу з'являється на сайті |
| `/rakhunok 3:1` | адмін | рахунок останнього зіграного матчу (`/rakhunok 2 3:1` — матчу №2) |
| `/pokaznyky 11 12 2 1 87` | адмін | показники гравця №11 в останньому матчі: очки, ейси, блоки, подача % (необов'язково) |
| `/match_vydalyty 2` | адмін | видалити матч №2 разом із його показниками |
| `/zayavky` | адмін | заявки команд на турнір із сайту |
| `/sklad` | усі | хто грає в найближчому матчі |
| `/liga` | адмін | оновити матчі й таблицю з siatka-lodzkie.org зараз |
| фото з підписом `/foto` | адмін | фото (чи альбом) з'являються на сторінці матчу; `/foto 3` — до матчу №3 |

Коли команда подає заявку на турнір на сайті, бот одразу пише про це в групу.

**Матчі ліги** бот сам бере з siatka-lodzkie.org (раз на годину, у середу — кожні 15 хв), разом з офіційною таблицею.
Опитування «хто грає» — у четвер о 10:00 перед матчем, нагадування — напередодні о 19:00 і за 3 години до гри.

**Panel kapitana** (`/admin` на сайті, лише для адміністраторів групи) — те саме кнопками: матчі поза лігою,
рахунок і партії, статистика гравців, фото, налаштування турніру, підтвердження оплати заявок,
жеребкування груп і результати ігор турніру.
Адміністратори групи бачать у кабінеті на сайті ще й відвідуваність усієї команди.

## Турнір

Назва, дата, місце, внесок, кількість місць і чи відкриті заявки — у `src/tournament.ts`.
Поки `date: null`, сайт пише «Termin wkrótce». Після зміни перезапусти API.

## Дані

Усе лежить у `data/db.json` (не потрапляє в git): тренування, голоси, учасники, сесії входу,
матчі, показники гравців і заявки на турнір.
Ключі сесій зберігаються лише як хеш. Налаштування — у `src/config.ts`.

## Запуск на сервері

Повна інструкція з Docker Compose і HTTPS — у [DEPLOY.md](../../DEPLOY.md). Коротко:


- API: `NODE_ENV=production` (cookies стають `Secure`, потрібен HTTPS), `BOT_TOKEN`, `PORT`,
  і `DATA_FILE` — шлях до `db.json` на постійному диску (інакше дані зникнуть після перезапуску контейнера).
- Сайт (`apps/web`): `API_URL` — адреса API, якщо він не на `localhost:4000`; `SITE_URL` — публічна адреса сайту
  (для превʼю посилань у соцмережах). Потім `npm run build` і `npm start`.
- Сайт і API мають бути на одному домені (сайт пересилає `/api/...` на API), тоді вхід через cookies працює без CORS.
