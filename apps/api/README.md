# API Pocket Aces (+ бот тренувань)

Один процес робить дві речі:

1. **Telegram-бот** у групі команди: опитування про тренування, нагадування, `/hto`, `/stat`.
2. **API для сайту** (`http://localhost:4000/api`): вхід через Telegram, кабінет гравця, відповіді «Będę / Nie dam rady».

Сайт (`apps/web`) звертається на `/api/...`, а Next.js пересилає це сюди (див. `rewrites` у `apps/web/next.config.ts`).

## Запуск (Windows, PowerShell)

```
cd apps\api
npm install
copy .env.example .env
```

Відкрий `apps\api\.env` і встав токен від @BotFather після `BOT_TOKEN=`. Потім:

```
npm start
```

Має з'явитися `API працює: http://localhost:4000/api` і `Бот @… працює`.
Сайт запускай в **іншому** терміналі: `cd apps\web` → `npm run dev`.

## Вхід на сайт через Telegram

1. На сайті `/logowanie` → «Zaloguj się przez Telegram».
2. Відкривається бот → **Start**. Бот перевіряє, що ти в групі команди.
3. Сайт сам помічає підтвердження і відкриває кабінет `/hub`.
4. Перший раз гравець обирає свою картку. Помилився — адмін пише в групі `/vidvyazaty 11`.

Хто вийшов із групи, протягом 10 хвилин втрачає доступ до кабінету.

## Команди бота

| Команда | Хто | Що робить |
|---|---|---|
| `/hto` | усі | хто буде на найближчому тренуванні |
| `/rozklad` | усі | постійний розклад і найближчі тренування |
| `/stat` | усі | хто скільки разів відмічався за 30 днів |
| `/trening 24.10 19:00 Зал` | адмін | разове тренування з опитуванням |
| `/rozklad_dodaty вт 19:00 Зал` | адмін | постійне тренування щотижня |
| `/rozklad_vydalyty 1` | адмін | прибрати постійне тренування №1 |
| `/skasuvaty` | адмін | скасувати найближче тренування |
| `/vidvyazaty 11` | адмін | відв'язати картку гравця на сайті |

## Дані

Усе лежить у `data/db.json` (не потрапляє в git): тренування, голоси, учасники, сесії входу.
Ключі сесій зберігаються лише як хеш. Налаштування — у `src/config.ts`.
